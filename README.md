# 匯率手札｜人民幣兌新臺幣每月分析與換算

> 看懂匯率，算好每一筆。

**[開啟互動網站](https://over-over-steak.github.io/cny-twd-exchange/)** ｜ **[查看完整程式碼](./index.html)**

本專案為「用 Vibe Coding 做出一個互動網頁」的實作作品。透過與 AI 討論需求、整理規格、產生與檢查程式碼，再使用 GitHub Pages 公開單一 HTML 網頁。

## 1. 專案目的與使用對象

提供人民幣計價商品的購物試算與每月匯率紀錄工具。使用者可以整理每日人民幣兌新臺幣匯率，觀察變化，並估算商品金額及手續費換算成新臺幣後的支出。

適合有人民幣換算需求、跨境購物需求，或想練習整理匯率資料的使用者。

**匯率方向統一為「1 人民幣（CNY）＝多少新臺幣（TWD）」**。數值越高，代表換取相同人民幣需要更多新臺幣。

## 2. 功能規格

| 功能 | 實作內容 |
| --- | --- |
| 月份篩選 | 預設顯示當月，可以切換其他月份的已存資料。 |
| 資料模式 | 正式資料與模擬資料分開保存、篩選及統計。 |
| 匯率走勢圖 | 使用 SVG 繪製折線圖，點選資料點可查看日期、匯率與來源。 |
| 每月統計 | 顯示所選月份最新一筆、最高、最低、平均匯率與資料筆數。 |
| 月內變動 | 比較該月最早與最晚日期的紀錄，顯示變動值與百分比。 |
| 雙向換算 | 人民幣換算新臺幣總支出，或以含手續費的新臺幣總預算估算可換得人民幣；匯率固定為 TWD / CNY。 |
| 價差比較 | 輸入同一商品人民幣金額、兩種匯率與共同手續費，顯示 A／B 總支出及較省方案。 |
| 手續費試算 | 輸入手續費百分比，顯示換算金額、手續費與預估總支出。 |
| 新增紀錄 | 輸入日期、正數匯率、來源及匯率種類。 |
| 編輯與刪除 | 可修改匯率與來源；刪除前須確認。編輯既有紀錄時日期固定。 |
| 重複日期處理 | 每個模式同一天只保留一筆，新增重複日期時詢問是否覆蓋。 |
| 瀏覽器儲存 | 使用 localStorage 保存兩種模式的資料；讀寫失敗時顯示提示。 |
| CSV 匯出 | 匯出目前月份、目前模式的日期、匯率、來源與資料模式。 |
| 響應式介面 | 繁體中文介面，依螢幕寬度調整電腦及手機版面。 |

## 3. 操作方式

### 快速體驗

1. 開啟上方網站連結。
2. 選擇觀察月份，點選「載入本月模擬資料」。此按鈕會為所選月份建立模擬資料。
3. 查看統計卡片與折線圖，點選資料點查看詳情。
4. 在換算區輸入人民幣金額、試算匯率與手續費。
5. 在下方紀錄表嘗試編輯、刪除，或匯出 CSV。

首次進入正式資料模式時，沒有紀錄而顯示「—」是正常狀態。載入模擬資料不會覆蓋正式資料；重建已有的同月模擬資料前會要求確認。

### 記錄自己的匯率

1. 將模式切換成「我的正式資料」。
2. 填寫日期、匯率及來源，例如銀行名稱與「即期賣出」種類。
3. 點選「新增紀錄」，圖表與統計會同步更新。
4. 建議同一組分析使用相同來源與匯率種類，避免將現金、即期、買入與賣出匯率混合比較。

下載專案後，也可以直接用瀏覽器開啟 `index.html`，不需要安裝 Python、Node.js 或額外套件。

## 4. 計算規則

| 項目 | 公式 |
| --- | --- |
| 換算金額（TWD） | 人民幣金額 × 匯率 |
| 手續費（TWD） | 換算金額 × 手續費百分比 ÷ 100 |
| 預估總支出（TWD） | 換算金額 ＋ 手續費 |
| 平均匯率 | 所選月份已收錄匯率總和 ÷ 紀錄筆數 |
| 月內變動值 | 最後一筆匯率 − 第一筆匯率 |
| 月內變動率 | （最後一筆匯率 − 第一筆匯率）÷ 第一筆匯率 × 100% |

金額顯示至小數點後兩位，匯率顯示至小數點後四位；運算使用原始數值，顯示時才四捨五入。

**換算範例（假設數值，非市場報價）：**

- 人民幣金額：100 CNY
- 匯率：4.5 TWD / CNY
- 手續費：1%
- 換算金額：450.00 TWD
- 手續費：4.50 TWD
- 預估總支出：**454.50 TWD**

### 雙向換算與價差比較（新增功能）

換算區新增方向選單。切換方向後，同一金額欄位改以所選貨幣解讀，請確認標籤後輸入金額。兩個方向的匯率均保持「1 CNY = 多少 TWD」，不用自行倒數。

反向換算將新臺幣金額視為**含手續費的總預算**：

- 換匯本金 = 新臺幣總預算 ÷（1 + 手續費百分比 ÷ 100）。
- 可換得人民幣 = 換匯本金 ÷ 匯率。
- 手續費 = 新臺幣總預算 − 換匯本金。

例如總預算 454.50 TWD、匯率 4.5、手續費 1%，可換得 100.00 CNY。

「兩種匯率，支出差多少？」為獨立試算區，不寫入每日紀錄。輸入 100 CNY、方案 A 匯率 4.4、方案 B 匯率 4.5、共同手續費 1%，A 總支出為 444.40 TWD，B 為 454.50 TWD，A 少付 10.10 TWD。預填匯率是示例，並非即時報價。

## 5. 異常與邊界情況

- 沒有資料：顯示空白狀態提示，不填入假統計數值。
- 只有一筆資料：可顯示最新、最高、最低及平均，但月內變動顯示資料不足。
- 匯率必須大於零；人民幣金額與手續費不得為負數。
- 日期、匯率與來源為新增紀錄的必填欄位。
- 換算數值過大而無法計算時，提示縮小金額。
- 無法儲存時顯示警告，提醒先匯出備份。

## 6. 資料來源與限制

**本網站不自動取得即時匯率，也不提供未來匯率預測。**

- 正式資料由使用者手動輸入並自行查證。
- 模擬資料由程式產生，明確標示為教學展示用途，不能視為真實市場報價。
- 當月模擬資料產生至瀏覽器當地日期的當天；其他選取月份產生整月模擬值。
- 統計僅涵蓋已收錄日期，不代表完整市場紀錄；缺漏日期不補值，圖表只連接現有紀錄。
- 換算結果為估算，實際成交仍依銀行或支付平台的匯率與收費方式決定。
- 資料保存在目前瀏覽器，不跨裝置同步，也不會因發布網站而上傳到 GitHub。
- 本機檔案與 GitHub Pages 的儲存空間彼此獨立；清除瀏覽器資料可能使紀錄消失。
- CSV 可供保存或使用試算表閱讀；目前未實作 CSV 匯入還原。
